# 接口字段映射说明

## products（商品表）
| 字段         | 类型           | 说明           |
| ------------ | -------------- | -------------- |
| id           | INT            | 商品ID         |
| name         | VARCHAR(100)   | 商品名称       |
| price        | DECIMAL(10,2)  | 商品价格       |
| merchant_id  | INT            | 商户ID         |
| created_at   | DATETIME       | 创建时间       |
| stock        | INT            | 库存           |
| image_url    | VARCHAR(255)   | 商品图片URL    |
| description  | VARCHAR(255)   | 商品描述       |

## merchants（商户表）
| 字段         | 类型           | 说明           |
| ------------ | -------------- | -------------- |
| id           | INT            | 商户ID         |
| name         | VARCHAR(50)    | 商户登录名     |
| shop_name    | VARCHAR(100)   | 店铺名称       |
| password     | VARCHAR(64)    | 登录密码（MD5）|
| created_at   | DATETIME       | 创建时间       |

## users（用户表）
| 字段         | 类型           | 说明           |
| ------------ | -------------- | -------------- |
| user_id      | INT            | 用户ID         |
| username     | VARCHAR(50)    | 用户名         |
| user_password| VARCHAR(64)    | 登录密码（MD5）|
| merchant_id  | INT            | 所属商户ID     |
| created_at   | DATETIME       | 创建时间       |
| is_admin     | TINYINT        | 是否管理员(1=是,0=否) |

## orders（订单表）
| 字段         | 类型           | 说明           |
| ------------ | -------------- | -------------- |
| id           | INT            | 订单ID         |
| merchant_id  | INT            | 商户ID         |
| product_id   | INT            | 商品ID         |
| quantity     | INT            | 购买数量       |
| status       | VARCHAR(20)    | 订单状态       |
| created_at   | DATETIME       | 下单时间       |
| total_amount | DECIMAL(10,2)  | 订单总金额     |

---

## 前后端接口字段建议
- 所有接口返回字段名与数据库字段保持一致。
- 时间字段统一用 `created_at`，金额用 `total_amount`，商品图片用 `image_url`。
- 用户登录接口：管理员用 `username`+`user_password`，商户用 `name`+`password`。
- 商品、订单、商户、用户的增删查改接口都用上述字段名。
