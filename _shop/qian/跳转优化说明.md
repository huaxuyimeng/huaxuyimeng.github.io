# 跳转优化说明

## 🎯 优化目标

提升用户登录和页面跳转的体验，实现智能、流畅的导航体验。

## ✨ 优化内容

### 1. 登录页智能跳转

**优化前：** 已登录用户访问登录页时仍显示登录表单
**优化后：** 已登录用户访问登录页时自动跳转到智能推荐页面

```javascript
// LoginView.vue - onMounted
onMounted(() => {

  // 检查记住的用户信息和自动登录

  attemptAutoLogin()

```

### 2. 智能跳转路径算法

**优先级顺序：**
1. **保存的重定向路径** - 用户被拦截时保存的目标页面
2. **最后访问页面** - 用户上次访问的页面
3. **用户默认页面** - 用户设置的默认首页
4. **角色默认页面** - 根据用户角色的兜底页面

```javascript
// auth.js - getSmartRedirectPath()
export function getSmartRedirectPath() {
  const userInfo = getUserInfo()
  if (!userInfo) return '/login'

  // 1. 检查是否有保存的重定向路径（优先级最高）
  const savedPath = getAndClearRedirectPath()
  if (savedPath && savedPath !== '/login' && canAccessPage(savedPath)) {
    return savedPath
  }

  // 2. 检查用户最后访问的页面（优先级次之）
  const lastVisited = getLastVisitedPage()
  if (lastVisited && canAccessPage(lastVisited) && lastVisited !== '/login') {
    return lastVisited
  }

  // 3. 检查用户设置的默认页面
  const defaultPage = getUserDefaultPage()
  if (defaultPage && canAccessPage(defaultPage)) {
    return defaultPage
  }

  // 4. 根据用户角色智能跳转（兜底方案）
  return getDefaultRedirectPath()
}
```

### 3. 路由守卫优化

**权限拦截时保存路径：**
```javascript
// 需要认证但未登录
if (!isAuthenticated()) {
  ElMessage.warning('请先登录')
  saveRedirectPath(to.fullPath)  // 保存当前路径
  next('/login')
  return
}

// Token失效时保存路径
if (!await validateToken(userInfo.token)) {
  ElMessage.error('登录已过期，请重新登录')
  localStorage.clear()
  saveRedirectPath(to.fullPath)  // 保存当前路径
  next('/login')
  return
}
```

**权限不足时智能跳转：**
```javascript
// 功能权限不足
if (to.meta.feature && !canAccess(to.meta.feature)) {
  ElMessage.error('权限不足，无法访问该功能')
  const redirectPath = getSmartRedirectPath()  // 使用智能跳转
  next(redirectPath)
  return
}
```


## 🔧 技术实现

### 核心函数

1. **getSmartRedirectPath()** - 智能跳转路径计算
2. **saveRedirectPath()** - 保存重定向路径
3. **getAndClearRedirectPath()** - 获取并清除保存路径
4. **saveLastVisitedPage()** - 保存最后访问页面
5. **canAccessPage()** - 检查页面访问权限

### 存储键值

- `redirectPath` - 保存的重定向路径
- `lastVisitedPage` - 最后访问页面
- `userDefaultPage` - 用户默认页面

## 📱 用户体验

### 登录流程

1. **未登录用户** → 正常登录流程
2. **已登录用户访问登录页** → 自动跳转到智能推荐页面

4. **登录失败** → 自动聚焦用户名输入框

### 权限拦截

1. **访问受保护页面** → 保存目标路径，跳转登录页
2. **登录成功** → 自动跳转回原目标页面
3. **权限不足** → 智能跳转到有权限的页面

2. **返回访问** → 优先跳转到上次访问页面
3. **角色切换** → 根据新角色智能跳转
