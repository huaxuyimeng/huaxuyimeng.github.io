# 商品管理系统

基于Vue 3 + Element Plus的商品管理系统，供商户管理员使用。

## 主要功能

- 浏览所有商品信息
- 搜索、筛选商品
- 创建、编辑、删除商品
- 展示商品的所属商户信息

## 技术栈

- Vue 3
- Element Plus
- Vue Router
- Axios

## 开发与部署

### 安装依赖

```
npm install
```

### 开发运行

```
npm run dev
```

### 构建生产版本

```
npm run build
```

### 预览生产版本

```
npm run preview
```
