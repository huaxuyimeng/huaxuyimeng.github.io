# 常用接口示例

## 1. 获取商品列表
- 请求：GET /api/products
- 响应：
```
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "name": "联想笔记本",
      "price": 5299.0,
      "merchant_id": 1,
      "created_at": "2025/6/20 15:26:53",
      "stock": 100,
      "image_url": "https://via.placeholder.com/300x200?text=商品图片",
      "description": "高性能笔记本电脑，适合办公和游戏"
    },
    ...
  ]
}
```

## 2. 新增商品
- 请求：POST /api/products
- 请求体：
```
{
  "name": "新商品",
  "price": 100,
  "merchant_id": 1,
  "stock": 10,
  "image_url": "http://...",
  "description": "描述"
}
```
- 响应：
```
{
  "code": 201,
  "message": "创建成功",
  "data": { ...新商品数据... }
}
```

## 3. 用户登录
- 请求：POST /api/merchants/user-login
- 请求体：
```
{
  "username": "admin1",
  "password": "123456"
}
```
- 响应：
```
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "user_id": 1,
    "username": "admin1",
    "merchant_id": 1,
    "is_admin": 1,
    "token": "...jwt..."
  }
}
```

## 4. 获取订单列表
- 请求：GET /api/orders
- 响应：
```
{
  "code": 200,
  "message": "success",
  "data": [
    {
      "id": 1,
      "merchant_id": 1,
      "product_id": 1,
      "quantity": 1,
      "status": "待发货",
      "created_at": "2025/6/20 10:30:00",
      "total_amount": 5299.0
    },
    ...
  ]
}
```

## 5. 新增订单
- 请求：POST /api/orders
- 请求体：
```
{
  "merchant_id": 1,
  "product_id": 1,
  "quantity": 2,
  "status": "待发货",
  "created_at": "2025/7/1 10:00:00",
  "total_amount": 10598.0
}
```
- 响应：
```
{
  "code": 201,
  "message": "创建成功",
  "data": { ...新订单数据... }
}
```
