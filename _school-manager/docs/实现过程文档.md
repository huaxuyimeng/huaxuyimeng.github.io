```vue
<!-- pages/user/login.vue -->
<template>
  <view class="login-form">
    <input v-model="formData.username" placeholder="用户名/学号" />
    <input v-model="formData.password" type="password" placeholder="密码" />
    <button @click="handleLogin">登录</button>

const handleLogin = async () => {
  // 验证表单
  if (!validateForm()) return

}
</script>
```

### 2.2 本地存储工具

**操作说明：**
封装统一的存储工具函数

**关键代码：**

```javascript
// utils/storage.js
const storage = {
  get(key, defaultValue = null) {
    const data = uni.getStorageSync(key)
    return data ? JSON.parse(data) : defaultValue
  },
  set(key, value) {
    uni.setStorageSync(key, JSON.stringify(value))
  },
  remove(key) {
    uni.removeStorageSync(key)
  }
}
export default storage
```

**测试效果：**
- ✅ 数据存储和读取正常

```vue
}
```

```javascript
// pages/tabbar/profile/index.vue
const handleCache = () => {
  uni.showModal({
    title: '清理缓存',
    content: `当前缓存大小：${cacheSize.value}`,
    success: (res) => {
      if (res.confirm) {
        // 清理临时缓存
        const keys = ['tempCache', 'imageCache', 'newsCache']
        keys.forEach(key => storage.remove(key))
        
        // 清理旧的历史记录
        const history = storage.get('browsingHistory') || []
        const filtered = history.filter(item => {
          return item.timestamp > Date.now() - 30 * 24 * 60 * 60 * 1000
        })
        storage.set('browsingHistory', filtered)
        
        cacheSize.value = '0MB'
        uni.showToast({ title: '缓存已清理' })
      }
    }
  })
}
```

**测试效果：**
- ✅ 缓存清理功能正常

### 3.4 API请求封装

**操作说明：**
统一封装API请求，处理token、错误等

**关键代码：**

```javascript
// api/request.js
function request(options = {}) {
  return new Promise((resolve, reject) => {
    const token = uni.getStorageSync('token')
    const header = {
      'Content-Type': 'application/json',
      ...(token && { Authorization: `Bearer ${token}` })
    }
    
    uni.request({
      url: baseURL + options.url,
      method: options.method || 'GET',
      data: options.data,
      header,
      success: (res) => {
        if (res.data.code === 200) {
          resolve(res.data.data)
        } else {
          handleError(res.data)
          reject(res.data)
        }
      },
      fail: reject
    })
  })
}
```

**测试效果：**
- ✅ 请求正常发送
- ✅ Token自动添加
- ✅ 错误统一处理
- ✅ 响应数据正确解析

## 四、功能优化与问题修复

### 4.1 组件问题修复

**问题：** `uni-rate` 组件不存在导致编译错误

**解决方案：**

```vue
<!-- 原代码 -->
<uni-rate :value="rating" />

<!-- 修复后 -->
<view class="stars-container">
  <uni-icons 
    v-for="(star, index) in 5"
    :key="index"
    :type="isStarFilled(rating, index) ? 'star-filled' : 'star'"
  />
</view>

<script>
const isStarFilled = (rating, index) => {
  return index < Math.round(rating)
}
</script>
```

**测试效果：**
- ✅ 编译错误消除
- ✅ 评分显示正常
- ✅ 视觉效果良好

### 4.2 模板优化

**问题：** 模板中直接使用Math对象

**解决方案：**

```vue
<!-- 优化前 -->
<view>{{ Math.round(rating) }}</view>

<!-- 优化后 -->
<view>{{ formatRating(rating) }}</view>

<script>
const formatRating = (rating) => {
  return Number(rating).toFixed(1)
}
</script>
```

**测试效果：**
- ✅ 代码更规范
- ✅ 兼容性更好
- ✅ 易于维护
